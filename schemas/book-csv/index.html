Book CSV Schema

This page documents the CSV schema for the /cms/data/books.csv endpoint.

Overview

The CSV export contains 36 columns per record with comprehensive bibliographic, physical, and cataloging metadata.

Column Structure

Key column groups include:

  • Bibliographic: title, author, ISBN, publisher, publication year
  • Physical: dimensions, page count, binding type, weight
  • Content: description, tags, classification
  • Collection: collection grouping, accession number, acquisition details
  • Media: image URL, cover image filename

Note: The price field is intentionally left empty per library policy.
