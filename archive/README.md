# Archive Directory

This directory contains outdated project files preserved for historical reference.

## Purpose

Files are archived here when they:
- Are no longer actively used but may have historical value
- Represent completed migrations or one-time tasks
- Contain dated information superseded by newer docs
- Are snapshots/reports from specific points in time

## Organization

**archive/2025-2026/** - Recent archived files (2025-2026)
- `.documentation-policy.json` - Documentation policy (not enforced)
- `failed-covers.json` - Failed cover acquisitions snapshot (Jan 2026)
- `url-database.json` - Publisher URL database (Nov 2025)
- `DATA-QUALITY-REPORT.md` - Data quality analysis (Nov 2025)
- `ELEVENTY-V3-MIGRATION.md` - Completed Eleventy v3 migration guide
- `claude-readme.md` - Duplicate Claude readme (superseded by root CLAUDE_README.md)
- `ARCHIVE_RECOMMENDATIONS.md` - Archive recommendations meta-doc

**docs/archive/** - Documentation archive (organized by topic/year)
- See docs/archive/ for archived documentation files

**scripts/archive/** - Script archive (deprecated code)
- See scripts/archive/ for archived scripts

## Policy

Archive directories are **tracked in git** to preserve project history.

Working directories (temp_covers/, etc.) are **ignored in git** via .gitignore.
