02 · Identity Guidelines
The wordmark

HUDSON STREET LIBRARY is set in Crimson Pro, Jacques Le Bailly's rework of Sebastian Kosch's Crimson Text. Crimson set every word of this site for years. It now keeps the door: the wordmark is the only place the face survives, and it appears nowhere else. Always capitals, always bold, tracked one hundredth of an em.

The lockup · every page header
HUDSON STREET LIBRARY

Mark height 1.3 em of the wordmark size, gap 0.55 rem, both set in the green. The mark and the words are one unit: do not separate them in the header, and do not let the line break.

The two-line setting is for print pieces and covers, where the strip lockup would run too wide. Green or ink, following the same colour rules as the mark.

Never set body text, headings, or anything else in Crimson Pro. A search of the site finding exactly one Crimson Pro declaration is correct, not an inconsistency to fix.

Never retrack, lowercase, or letter-space the wordmark for effect. It is a fixed setting, not a style.
