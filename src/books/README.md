# `src/books/`

Most book pages are now **generated by Eleventy** from `src/_data/books.csv`
via the `src/books.njk` layout — they are not hand-authored HTML in this
directory.

## What's still here

```
src/books/
├── art/                 # Hand-authored art-book pages predating the CSV port
├── collections/         # Collection-specific overrides
│   └── queer/
├── general/             # Pre-CSV general entries
├── magazines/           # Magazine-specific pages
├── templates/           # Templates and disabled scaffolds
└── README.md
```

Items in `art/`, `collections/`, `general/`, and `magazines/` are legacy
HTML pages that haven't been migrated into the CSV yet. New books should be
added through the CSV workflow, not by dropping HTML here:

```bash
npm run add
# or edit src/_data/books.csv directly and run npm run test:csv
```

See `docs/ADD-BOOK-GUIDE.md` for the add flow and
`docs/PATH-STRUCTURE.md` for how Eleventy produces `/books/<slug>/`.

## Naming convention (for legacy HTML only)

When a hand-authored page is needed, follow:

```
Artist_FirstName_LastName-Book_Title.html
```

Spaces become underscores; a hyphen separates artist from title. Examples:

- `Vince_Aletti-Physique.html`
- `Ken_Schles-Invisible_City.html`

Collection links from inside a subdirectory should reference
`../../../collections/<collection-name>.html`.

## Templates

`templates/BOOK-TEMPLATE.html` is the historical scaffold used by the
pre-Eleventy generator. The canonical book layout is now
`src/_includes/layouts/book.njk`, which renders rows from `books.csv`.
