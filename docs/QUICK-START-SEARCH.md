# Quick Start: Search and Browse Features

## Finding Books

### 1. Basic Search
Visit the [Search page](/aggregate-view.html) to:
- Search by title, author, publisher, or description
- Filter by publisher, year, collection, or tags
- Sort by title, author, year, or publisher
- Toggle visual browse mode for image-focused exploration

### 2. Clickable Metadata
Click on any metadata field in book cards to explore related books:

| Click on... | To see... |
|-------------|-----------|
| Publisher name | All books by that publisher |
| Year | All books from that year |
| Author name | All books by that author |
| Tag pill | All books with that tag |
| Collection badge | All books in that collection |

### 3. Direct Links to Filtered Views
You can bookmark or share specific filtered views:
```
/aggregate-view.html?filter=publisher&value=Steidl
/aggregate-view.html?filter=year&value=2020
/aggregate-view.html?filter=tag&value=Photography
/aggregate-view.html?filter=collection&value=NYC%20Photobooks
```

## Visual Browse Mode
Toggle "Visual Browse" to see books in a grid layout:
- Compact 6-column grid on desktop
- Focus on cover images
- Hover to see full titles
- Click metadata to filter

## Advanced Filtering
Combine multiple filters:
1. Start with an aggregate view (e.g., all Steidl books)
2. Add search terms to narrow results
3. Apply additional filters (year, collection, etc.)
4. Sort results as needed

## Tag Exploration
- Only 18.5% of books currently have tags
- Browse 154 unique tags
- Top tags: Photography, NYC, Fashion
- Click any tag to see related books

## Cover Images
- 56.8% of books have cover images
- Filter by "With Covers" or "Without Covers"
- Missing covers show placeholder with title

## Tips
- Use quotes in search for exact phrases
- Clear all filters with the red "Clear All Filters" button
- Active filters show at the top with a clear button
- Results update instantly as you type or change filters
