Le Petit Voyeur Issue 5

2016

About This Issue

Issue 5 features 28 artists including photographers Mario Testino and Todd Hido, alongside contemporary artists like Felipe Pantone and El Mac. Each magazine is individually hand-numbered by a bookbinder.

Cover artwork by Eric T. White.
